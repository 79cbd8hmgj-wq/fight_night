FIGHT NIGHT ROUND 3 PSP
OVERHAUL-SCOPE FUNCTIONAL REVERSE-ENGINEERING
INFRASTRUCTURE SHELL

Purpose
=======

This document defines the repository infrastructure that should exist before
large-scale subsystem reverse engineering begins.

The shell is intentionally evidence-safe.

It provides:

- Repository structure
- Shared data models
- Evidence confidence rules
- Runtime-address and file-offset types
- Subsystem package templates
- Binary and instruction guards
- Runtime trace schemas
- Replacement-boundary models
- Completion validators
- Testing structure
- Command-line interface structure
- Phase I and Phase II gates
- Explicit failure behavior for unknown systems

It does not provide:

- Guessed combat formulas
- Guessed boxer-record layouts
- Guessed save structures
- Final AI architecture
- Final career-state architecture
- Unverified MIPS hooks
- Placeholder gameplay behavior that silently returns fake values

Unknown behavior must remain visibly unknown until static and runtime evidence
supports a confirmed implementation.


1. PROJECT PRINCIPLE
====================

Before overhaul implementation begins, every system modified by the overhaul,
and every system that owns, stores, calls, displays, saves, or consumes its
data, must be functionally reverse-engineered to a verified replacement
boundary.

Unrelated systems require only interface mapping or inventory unless later
evidence shows that they affect an overhaul system.

The project uses three subsystem classes:

Class A
-------

Functional reconstruction required.

A Class A package is complete only when it contains:

- Confirmed symbols
- Confirmed structures and fields
- Caller and consumer inventories
- Readable original-behavior reconstruction
- Runtime evidence
- Regression tests
- Save and UI impact analysis
- A documented replacement boundary

Class B
-------

Interface-boundary mapping required.

A Class B package must identify:

- Public entry points
- Inputs and outputs
- Memory ownership
- Error behavior
- Callers used by Class A systems
- Compatibility requirements

Its internals do not need a complete functional reconstruction unless it is
later promoted to Class A.

Class C
-------

Inventory only.

A Class C package records:

- Module or resource identity
- Load location
- High-level purpose
- Known dependencies
- Reason it is currently outside overhaul scope

```python
class FNR3Error(Exception):
    """Base exception for the reverse-engineering framework."""


class UnsupportedRevisionError(FNR3Error):
    """Raised when an image or binary does not match a supported revision."""


class EvidenceNotConfirmedError(FNR3Error):
    """Raised when code attempts to use unconfirmed behavior as authoritative."""


class GuardMismatchError(FNR3Error):
    """Raised when expected original bytes or hashes do not match."""


class IncompleteSubsystemError(FNR3Error):
    """Raised when a subsystem package fails its completion contract."""


class ReplacementBoundaryError(FNR3Error):
    """Raised when a proposed replacement boundary is incomplete or unsafe."""


class CopyrightPolicyError(FNR3Error):
    """Raised when repository output would include prohibited game data."""
```


4. ADDRESS MODEL
================

Runtime addresses, ELF-relative offsets, file offsets, archive-entry offsets,
and ISO extents must never be represented as interchangeable integers.

File:
src/fnr3_re/addresses.py

```python
from dataclasses import dataclass
from enum import StrEnum


class AddressSpace(StrEnum):
    PSP_RUNTIME = "psp_runtime"
    ELF_VIRTUAL = "elf_virtual"
    ELF_FILE = "elf_file"
    MODULE_RELATIVE = "module_relative"
    ARCHIVE_ENTRY = "archive_entry"
    ISO_FILE = "iso_file"
    ISO_LBA = "iso_lba"


@dataclass(frozen=True, slots=True)
class Address:
    space: AddressSpace
    value: int
    module: str | None = None
    source_file: str | None = None

    def __post_init__(self) -> None:
        if self.value < 0:
            raise ValueError("Address values must be non-negative")

        if self.space in {
            AddressSpace.PSP_RUNTIME,
            AddressSpace.ELF_VIRTUAL,
            AddressSpace.MODULE_RELATIVE,
        } and not self.module:
            raise ValueError(f"{self.space} requires a module name")


@dataclass(frozen=True, slots=True)
class AddressRange:
    start: Address
    size: int

    def __post_init__(self) -> None:
        if self.size <= 0:
            raise ValueError("AddressRange size must be positive")

    @property
    def end_exclusive(self) -> int:
        return self.start.value + self.size
```

Rules:

- Never accept raw integers in public APIs when the address space matters.
- Conversions require a validated module mapping.
- Conversion failures must raise an explicit exception.
- Runtime observations must record module identity and load base.
- File patches must use file or module-relative offsets, not naked runtime
  addresses.


5. EVIDENCE CONFIDENCE MODEL
============================

File:
src/fnr3_re/evidence/confidence.py

```python
from enum import StrEnum


class EvidenceConfidence(StrEnum):
    CANDIDATE = "candidate"
    PROBABLE = "probable"
    CONFIRMED = "confirmed"
    REJECTED = "rejected"
```

Definitions:

Candidate
---------

A plausible interpretation supported by one or more observations but lacking
sufficient static or runtime proof.

Probable
--------

Supported by multiple independent observations, but one important control,
lifecycle check, or alternate-path check remains incomplete.

Confirmed
---------

Supported by exact executable or resource evidence and controlled runtime
validation where runtime behavior matters.

Rejected
--------

A prior interpretation contradicted by stronger evidence.

Rules:

- Only CONFIRMED evidence may define authoritative structure fields,
  replacement code, save migrations, or implementation claims.
- REJECTED evidence remains preserved to prevent repeated investigation.
- Promotion requires recording prior status, new evidence, reviewer, and date.
- Confidence applies to individual claims, not merely whole files.

10. UNKNOWN-BEHAVIOR POLICY
===========================

Unconfirmed functions must fail explicitly.

```python
from fnr3_re.errors import EvidenceNotConfirmedError


def calculate_original_punch_cost(context: "PunchContext") -> int:
    raise EvidenceNotConfirmedError(
        "The original punch-cost calculation has not reached a "
        "verified replacement boundary."
    )
```

Forbidden placeholder behavior:

```python
def calculate_original_punch_cost(context):
    return 0
```

```python
def calculate_original_damage(context):
    return context.power
```

Allowed temporary behavior:

- Raise EvidenceNotConfirmedError.
- Return a typed evidence-bound value that cannot be consumed as confirmed.
- Load evidence artifacts without interpreting unknown fields.
- Record raw bytes, addresses, hashes, and observations.


11. EVIDENCE-BOUND VALUE
========================

```python
from dataclasses import dataclass
from typing import Generic, TypeVar

from fnr3_re.evidence.confidence import EvidenceConfidence
from fnr3_re.errors import EvidenceNotConfirmedError

T = TypeVar("T")


@dataclass(frozen=True, slots=True)
class EvidenceBoundValue(Generic[T]):
    value: T
    confidence: EvidenceConfidence
    claim_id: str

    def require_confirmed(self) -> T:
        if self.confidence is not EvidenceConfidence.CONFIRMED:
            raise EvidenceNotConfirmedError(
                f"Claim {self.claim_id} is {self.confidence}, not confirmed"
            )
        return self.value
```

17. BINARY AND INSTRUCTION GUARDS
=================================

File:
src/fnr3_re/executable/instruction_guard.py

```python
from dataclasses import dataclass
from hashlib import sha256

from fnr3_re.errors import GuardMismatchError


@dataclass(frozen=True, slots=True)
class ByteGuard:
    source_name: str
    offset: int
    expected_hex: str
    expected_sha256: str | None = None

    def validate(self, payload: bytes) -> None:
        expected = bytes.fromhex(self.expected_hex)
        actual = payload[self.offset:self.offset + len(expected)]

        if actual != expected:
            raise GuardMismatchError(
                f"{self.source_name} guard mismatch at 0x{self.offset:X}"
            )

        if self.expected_sha256 is not None:
            digest = sha256(actual).hexdigest()
            if digest != self.expected_sha256:
                raise GuardMismatchError(
                    f"{self.source_name} hash mismatch at 0x{self.offset:X}"
                )
```

Rules:

- Every patch validates original bytes before changing them.
- Every replacement validates source revision and module hash.
- Instruction hashes supplement exact-byte guards.
- Failed guards produce no partial output.
- Rebuilders use transactional temporary files.

23. SUBSYSTEM COMPLETION VALIDATOR
==================================

```python
from dataclasses import dataclass

from fnr3_re.errors import IncompleteSubsystemError


@dataclass(frozen=True, slots=True)
class CompletionCheck:
    check_id: str
    passed: bool
    details: str


@dataclass(frozen=True, slots=True)
class CompletionReport:
    subsystem_id: str
    checks: tuple[CompletionCheck, ...]

    @property
    def passed(self) -> bool:
        return all(check.passed for check in self.checks)

    def require_pass(self) -> None:
        if not self.passed:
            failures = [
                f"{check.check_id}: {check.details}"
                for check in self.checks
                if not check.passed
            ]
            raise IncompleteSubsystemError("\n".join(failures))
```

- consumers_inventory_complete

- original_behavior_reconstructed
- runtime_vectors_present
- regression_tests_pass
- save_impact_documented

24. PHASE I GLOBAL GATE
======================

```python
from dataclasses import dataclass

from fnr3_re.errors import IncompleteSubsystemError


@dataclass(frozen=True, slots=True)
class PhaseOneSubsystemResult:
    subsystem_id: str
    required: bool
    complete: bool
    report_path: str


def require_phase_one_complete(
    results: tuple[PhaseOneSubsystemResult, ...],
) -> None:
    failures = [
        result
        for result in results
        if result.required and not result.complete
    ]

    if failures:
        names = ", ".join(result.subsystem_id for result in failures)
        raise IncompleteSubsystemError(
            "Phase II is locked. Incomplete Class A subsystems: "
            f"{names}"
        )
```

Phase II remains locked until:

- Every Class A subsystem passes.
- Every Class B interface boundary passes.
- Module memory budget is approved.
- Save migration feasibility is approved.
- UI feasibility is approved.
- Performance risks are documented.
- A decompilation-completeness review is approved.

36. CHECKPOINT POLICY
=====================

Each reverse-engineering checkpoint answers one evidence question only.

A checkpoint ends after:

1. Writing or updating one evidence artifact.
2. Recording one bounded result or negative result.
3. Running focused tests.
4. Updating subsystem status.
5. Committing the checkpoint.
6. Reporting the result.

Large disassembly and debugger logs remain local. Repository artifacts retain
addresses, hashes, selected values, controls, conclusions, and confidence.

- The CLI displays every shell command.

42. FINAL RULE
==============

The shell organizes reverse engineering. It must not predetermine its answers.

Correct progression:

```text
Create infrastructure shell
→ validate exact build
→ extract and rebuild reproducibly
→ map modules and resources
→ create subsystem evidence packages
→ perform static discovery
→ perform controlled runtime validation
→ reconstruct original behavior
→ document replacement boundaries
→ pass the global Phase I gate
→ authorize Phase II
→ implement the overhaul
```

Any code that attempts to skip from infrastructure directly into unverified
gameplay implementation should fail loudly.
