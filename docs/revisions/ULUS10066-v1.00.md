# ULUS10066 revision 1.00 lock

Task 3 rejects every image except the known USA retail revision before extraction, patching, rebuilding, or runtime research begins.

## Locked identity

| Property | Expected value |
|---|---|
| Revision ID | `ULUS10066-v1.00` |
| Disc ID | `ULUS10066` |
| Disc version | `1.00` |
| Title | `EA SPORTS™ FIGHT NIGHT Round 3` |
| Required PSP system version | `2.60` |
| ISO size | `1,137,737,728` bytes |
| ISO SHA-256 | `b11da5afe208d9791eecd9f6a44d0f57946f7d9de165b7d8dd22f5ee740f4ee2` |

The SHA-256 and size provide the hard revision lock. `PARAM.SFO` is read independently from the ISO9660 filesystem and checked as a diagnostic control so a mislabeled, truncated, modified, or wrong-region image produces specific evidence.

## Command

```bash
fnr3-re validate-image /path/to/game.iso \
  --revision-config config/revisions/ulus10066-v1.00.json
```

Use `--json` for deterministic machine-readable output.

## Integration test

The copyrighted reference image remains local and must never be committed. Set:

```bash
export FNR3_REFERENCE_ISO=/absolute/path/to/Fight\ Night\ Round\ 3\ \(USA\).iso
python -m pytest tests/integration/test_reference_revision.py -q
```

Without that environment variable, the reference-image integration test is explicitly skipped. Unit tests use generated ISO9660 and PARAM.SFO fixtures only.

## Evidence boundary

This lock confirms image identity. It does not yet confirm a no-change rebuild, module load addresses, PRX ownership, or executable replacement feasibility. Those remain later Phase I tasks.
